Codex Guide

把需求讲清楚，AI 才能把活做清楚

这页是活动中的入门速览。目标不是让你立刻成为程序员，而是让你学会把一个想法交给 Codex，并看懂它正在做什么。

01

Codex 是什么

Codex 是能阅读项目文件、修改代码、运行检查并解释结果的 AI 编程协作者。你给它目标，它把目标拆成可以执行的步骤。

02

能帮普通人做什么

它适合把重复流程做成小工具：报名表、订单整理、学习清单、活动页面、资料归档、简单后台和自动检查。

03

如何写好需求

说清楚使用者、页面内容、字段名称、不能做什么，以及怎样算完成。越具体，Codex 越容易一次做对。

04

多 Agent 协作是什么

复杂项目可以让不同 Agent 分工：前端管页面，后端管数据，内容 Agent 管文案，测试 Agent 管验收。

05

常见误区

不要一上来要求“大而全的平台”。先做最小可用版本；不要只说“做得好看”，要给页面、内容、字段和验收标准；不要只看命令成功，要打开真实页面检查。
