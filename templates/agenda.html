Agenda

一场能跟上的 90 分钟工作坊

整场活动围绕一个问题展开：普通人怎样把脑子里的想法，变成一个可以被 Codex 逐步执行的小项目。我们会先建立共同语言，再进入现场实战。

19:00 - 19:10

破冰：普通人为什么要理解 AI Agent

从生活和工作中的重复问题开始，理解 AI Agent 更像一个可被指挥的协作者，而不是万能答案机。

19:10 - 19:20

Codex 是什么

用普通人能听懂的方式介绍 Codex：它可以读项目、改文件、运行检查，但仍然需要清楚任务和人工验收。

19:20 - 19:35

如何把想法写成清楚需求

把一句模糊想法拆成目标、背景、约束、输出格式和验收标准，让 Codex 知道该做什么、不该做什么。

19:35 - 19:50

如何让 Codex 分阶段完成任务

学习先搭骨架、再补内容、再测试修正的节奏，避免一次性把需求塞得过大。

19:50 - 20:05

多 Agent 协作演示

用 Content Agent、Frontend Agent、Backend Agent 的分工示例，理解同一个项目里不同角色如何协作。

20:05 - 20:25

现场实战：做一个小工具

选择一个轻量需求，现场让 Codex 生成页面或流程，并一起检查它是否真的能运行、是否符合需求。

20:25 - 20:30

Q&A 和交流

围绕大家自己的工作、内容、教育或创业场景，讨论哪些想法适合先做成小工具。
